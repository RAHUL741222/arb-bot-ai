## 2025-07-25 - Localized Assistive Content and Button-Level State Transitions
**Learning:** For application interfaces that heavily leverage native localization (such as Bengali text for core actions), screen reader assets (such as `contentDescription`) must strictly align with the local language context to ensure consistency in auditory feedback. Furthermore, embedding small action-level `CircularProgressIndicator` elements inside primary action buttons while disabling them prevents redundant asynchronous triggers and provides immediate interaction feedback without interrupting the overall layout.
**Action:** Always check the active language of the interface before writing accessibility labels, and default to inline loader components (size 20.dp, stroke 2.dp) for any async primary action trigger.
