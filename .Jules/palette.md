## 2025-02-15 - [Bengali Accessibility & Loading Indicators]
**Learning:** For application modules localized in Bengali, icon-only buttons need precise Bengali content descriptions rather than general English content descriptions to provide a unified Screen Reader experience. Additionally, primary transaction scan triggers must handle async state loading gracefully inside the button component itself, disabling further interaction to avoid concurrent network trigger actions, using exactly defined visual dimensions (size = 20.dp, strokeWidth = 2.dp) for the loading indicator to prevent layout shifts.
**Action:** Always inspect the primary app language/localization before writing screen-reader accessibility tags (such as `contentDescription` attributes in Jetpack Compose). Always disable the primary CTA buttons when their respective asynchronous operations are running, and style inline progress indicators specifically using standard dimensions of 20.dp size with 2.dp stroke width.
